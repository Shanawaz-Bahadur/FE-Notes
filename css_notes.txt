==> CSS question

Q) Explain CSS Box Model
Ans) The CSS Box Model is a fundamental concept that treats every HTML element as a rectangular box.

    Total Width=margin+border+padding+content
    Box model consists of:

        - content
        - padding
        - border
        - margin

Q) Difference between content-box and border-box?
Ans) Mainly we do box-sizing: border-box; at the start of the project, just to avoid overflow of border or padding once we make any updates

    content-box (default)
        Width excludes:

        - padding
        - border

    border-box (Usually preferred)
        Width includes:

        - padding
        - border

Q) Difference between Flexbox and Grid?
Ans) Both are used to create the responsive layout:

    Feature             Flexbox                                 Grid

    Dimension    1D (Row or Column)                         2D (Rows and Columns)
    Approach        Content First                           Layout First
    Best For    Aligning single lines of items          Complex page structures & grids
    Spacing     gap, justify-content, align-items       grid-template-columns, gap, grid-area

Q) Difference between relative, absolute, fixed and sticky?
Ans)
    - relative: Position relative to itself.
    - absolute: Relative to nearest positioned parent, it gets up in their dimension once position is set to absolute
    - fixed: Relative to viewport.
    - sticky: Acts relative until scroll threshold.

    Note: Without setting the position value we cannot use top, left, right, bottom

Q) What is the Difference between inline, block and inline-block
Ans) 
    Block elements:

        - always start on a new line
        - take full available width by default

    Inline elements:

        - do NOT start on new line
        - only take required content width

    *** Important Limitation of Inline Elements

        -- Width and height usually do NOT work properly.

    Inline-block:

        - behaves like inline
        - BUT allows width/height like block
        - Elements appear side-by-side
        - Width/height works properly

Q) What are the different type of units in CSS?
Ans) 
    - Absolute:

        px: Absolute unit, Fixed size, Does NOT scale relative to parent 

    - Relative:

        em: Relative to Parent Element's Font Size

            <div style="font-size:20px">
                <p style="font-size:2em">Hello</p>
            </div>

            Calculation:
                2em=2×20px=40px

        rem: Relative to Root (html) Font Size
            Example:
                Usually browser default:
                    html {
                        font-size: 16px;
                    }

                My element CSS:
                    font-size: 2rem;

            Calculation:
                2rem=2×16px=32px


        %: Depends on parent dimension.
            Example:

                width: 50%; Meaning: 50% of parent width
        
        vh: Viewport Height
            Example: height: 100vh; Meaning: 100% of screen height

            If screen height = 900px

                100vh=900px

        vw: Viewport Width
            Example: width: 100vw; Meaning: full screen width

            If viewport width = 1200px

                100vw = 1200px

Q) What are pseudo-class and pseudo-element?
Ans) 

    1. Pseudo-classes (:) target an existing element when it enters a specific state (e.g., being hovered over).

        Example:
            :hover – Styles an element when the mouse is over it.
            :nth-child(n) – Targets the nth child of a parent.
            :focus – Styles an element when it has keyboard focus.
            :visited – Styles links the user has already clicked.

    Pseudo-elements (::) target a specific part of an element or create a "virtual" element that isn't in the HTML (e.g., styling just the first line of a paragraph).

        Example:

            ::before / ::after – Inserts decorative content before or after an element's actual content (requires the content property).
            ::first-letter – Styles only the very first letter of a block of text.
            ::selection – Styles the part of the document currently highlighted by the user.

Q) What are media queries?
Ans) Used for responsive design.

    Example:
        @media (max-width: 768px) {
            .container {
                flex-direction: column;
            }
        }
