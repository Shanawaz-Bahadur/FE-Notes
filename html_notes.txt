Q) What is semantic HTML and why is it important?
Ans) Semantic HTML means using meaningful tags that describe the purpose of the content.
    Examples:

        <header>
        <article>
        <section>
        <nav>
        <footer>

    instead of only using <div> everywhere.There Benefits:

        - Better accessibility
        - Better SEO
        - Easier maintenance
        - Better readability
        - Helpful for screen readers

Q) What are inline, block and inline-block elements?
Ans) Block
        - takes full width
        - starts on new line

    Examples:
        div
        p
        section

    Inline
        - takes content width
        - no new line

    Examples:
        span
        a
        strong

    Inline-block
        - behaves inline
        - but can set width/height

Q) What is the difference between HTTP and HTTPS?
Ans) HTTP is a protocol used for communication between client and server, but it transfers data in plain text. HTTPS is the secure version of HTTP that uses SSL/TLS encryption to protect data transmission, making communication secure and reliable.

Q) What is <!DOCTYPE> in HTML?
Ans) <!DOCTYPE> declaration in HTML specifies the type and version of the document being used, helping browsers render the content correctly by using the appropriate standards and rendering modes.

Q) What are the differences between the <canvas> and <svg> elements in HTML5?
Ans) Both <canvas> and <svg> are used for rendering graphics in HTML5, but they work differently.

    - <canvas> is pixel-based and works like a drawing board. Graphics are drawn using JavaScript.
    - <svg> is vector-based and uses XML elements to define graphics.

Q) What are HTML templates? How can they improve web performance?
Ans) HTML templates are reusable chunks of HTML markup that are defined using the <template> tag. The content inside a <template> tag is not rendered immediately when the page loads. It remains inactive until it is explicitly used through JavaScript.

    Example

        <template id="cardTemplate">
            <div class="card">
                <h2>Title</h2>
                <p>Description</p>
            </div>
        </template>

    Using JavaScript:

        const template = document.getElementById("cardTemplate");
        const clone = template.content.cloneNode(true);
        document.body.appendChild(clone);
